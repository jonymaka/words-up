# Words Up — 初中英语词汇学习网页

> 需求文档（活文档：随需求与设计变更及时更新）

## 一、项目定位

面向**初中学生**（中考词汇）的**英语单词学习网页**，主场景为**学生自习**（学生独立打开网页自学，不依赖老师或家长在场）。

### 3.2 功能需求（2026-08-29 确认）

需要以下全部学习功能：

- [ ] 单词卡片浏览：音标、词性、释义、例句、发音
- [ ] 记忆模式（背单词）：认识/不认识标记，自动安排复习
- [ ] 自测练习：选择题/拼写题，即时判分
- [ ] 听写/听力模式：听发音 → 写单词
- [ ] 错词本：记录错词，集中重练

### 3.3 进度与激励（2026-08-29 确认）

- [ ] 学习进度统计（各单元已学/未学、掌握率、正确率）
- [ ] 记忆曲线复习提醒（间隔重复）
- [ ] 连续打卡/成就（徽章等激励）
- [ ] 导出学习报告（给家长/老师）

### 3.4 内容来源（2026-08-29 确认）

- 词库以**用户导入/可配置**为主：提供 **JSON 导入**接口，老师/家长自行维护词表
- 内置**最小示例词库**供直接体验
- 词条字段：单词 / 音标 / 词性 / 释义 / 例句（+ 例句中文），可扩展

### 3.5 技术形态（2026-08-29 确认）

- **多文件静态站点**（index.html + css/ + js/ 分离），无需服务器、无需账号
- 数据存浏览器本地（localStorage），不依赖后端

### 3.6 发音方案（2026-08-29 确认，2026-08-29 定为方案 C）

- 目标：**微软免费 TTS**（edge-tts，神经网络音色）
- 现实约束：微软 TTS 无法被网页直接调用（CORS 限制），需本地小代理转发
- **最终方案（方案 C）**：微软 TTS 优先；本地代理未启动时**自动降级**为浏览器原生语音（Web Speech API），保证"打开即用"
- 已确认本机 edge-tts 库就绪，代理用 Python 实现（约 50 行）

### 3.7 设备与风格（2026-08-29 确认）

- 设备：**响应式适配**，电脑 + 手机/平板都要好看好用
- 风格：**清新活力学习风**（明亮配色、圆角卡片、友好视觉）

### 3.8 AI 辅助功能（2026-08-29 提出，2026-08-29 确认）✅

在词库导入之外，增加 AI 能力：

- [ ] **AI 词条自动生成**：手动添加一个单词（只需输入单词本身），系统经 AI 自动生成音标、词性、释义、例句、例句中文等字段
  - 流程：AI 结果填入「新词表单」→ 用户逐字段审阅/修改 → 点保存入库（**生成后先预览确认**，防止 AI 出错）
- [ ] **智能评价-学情分析报告**：AI 根据学习记录（错词、正确率、复习情况）自动生成阶段性学习分析与改进建议（可导出）
- [ ] **智能评价-答题智能解析**：自测/听写答错时，AI 解释错误原因并给记忆方法（如区分易混词）
- 排除：发音评测（需麦克风+语音识别，复杂度高，明确不做）

**AI 技术配置（2026-08-29 确认）**：

- 服务商：**通用 OpenAI 兼容格式**（配置 base_url + api_key 即可切换 DeepSeek/OpenAI/通义/智谱 等）
- 调用方式：**浏览器直连**（key 存 localStorage，网页直接请求 AI 接口）
  - ⚠️ CORS 现实已处理（2026-08-29 设计确认）：服务商若拦截浏览器直连，采用「连接自检 + 引导」策略，见 6.5 节

## 四、备选方案记录

1. **方案 A**：静态站点 + 本地代理，只用微软 TTS —— 音质好，但需要代理启动步骤

### 6.2 数据结构

**词库 JSON 格式**（用户/家长维护，导入即用）：

```json
{
  "version": 1,
  "name": "人教版七年级上",
  "grades": [
    {
      "id": "g7",
      "name": "七年级上",
      "units": [
        {
          "id": "u1",
          "name": "Unit 1",
          "title": "Making Friends",
          "words": [
            {
              "word": "name",
              "phonetic": "/neɪm/",
              "pos": "n.",
              "meaning": "名字",
              "example": "My name is Tom.",
              "exampleCn": "我的名字叫汤姆。"
            }
          ]
        }
      ]
    }
  ]
}
```

**进度存储**（localStorage）：每词掌握状态（新词/学习中/已掌握 + 熟练度 0-5）、正确/错误次数、上次学习/下次复习时间；打卡日期、成就徽章记录。

### 6.3 核心功能模块

| 模块 | 行为 |
|---|---|
| 卡片浏览 | 单元词表 → 单词卡片：词、音标、词性、释义、例句、发音按钮；翻页/随机 |
| 记忆模式 | 认识/不认识标记；认识词按间隔重复（10分钟→1天→3天→7天→14天…）排复习队列，不认识的立即重学 |
| 自测练习 | 英译中单选 / 中译英单选 / 拼写题，即时判分+解析，错词自动进错词本 |
| 听写模式 | 播放发音 → 学生输入拼写 → 判分；可调语速 |
| 错词本 | 自动汇总各模式错词，一键重练，可手动移除 |
| 统计/激励 | 今日任务、打卡日历、单元进度、成就徽章、复习提醒 |
| 导出 | 学习报告导出（进度/错词/打卡） |

### 6.4 发音引擎（方案 C）

tts.js 启动时探测本地代理 `http://localhost:8765/health`：在线→用微软 TTS 音色（`/tts?text=..&voice=..` 返回 mp3）；离线→自动降级浏览器原生语音（speechSynthesis），功能不受影响。代理 proxy.py 用已装 edge-tts 监听 8765，双击 start.command 启动。

### 6.5 AI 集成（2026-08-29 设计确认）

| 项 | 决策 |
|---|---|
| 接口 | 通用 OpenAI 兼容（`POST {base_url}/chat/completions`），可配模型名 |
| 配置存储 | base_url + api_key + 模型 存 localStorage，提供「连接自检」 |
| CORS 策略 | A 直连+自检为主；被拦则明确提示该服务商不支持浏览器直连、引导用户；C 兜底：AI 失败不影响学习功能、可后补 |
| 词条生成 | 输入单词 → 「AI 生成」→ 结果强制解析为 JSON（phonetic/pos/meaning/example/exampleCn）填入表单 → 预览确认/修改 → 保存入库；解析失败提示重试，不污染词库 |
| 学情报告 | 从统计页进入；汇总错词/正确率/复习情况发给 AI → 生成分析+建议 → 可导出 |
| 答题解析 | 自测/听写判错后，每题提供「AI 解析错误」按钮 → 解释错因+记忆方法 |

**默认服务商（2026-08-29 实测）**：Agnes 2.5 Flash —— Base URL `https://api.agnes-ai.cn/v1`，模型 `agnes-2.5-flash`；标准 OpenAI 兼容格式，CORS 实测允许 *（浏览器直连可用）。js/ai.js 客户端同时兼容 DeepSeek / OpenAI / 通义 / 智谱等 OpenAI 格式服务。Key 仅存本机 localStorage；AI 失败只做提示（含 CORS/鉴权/JSON 解析分类错误），绝不污染词库、不阻断学习功能。

### 6.6 界面与错误处理

- 清新活力风：明亮渐变、圆角卡片、表情图标；响应式（桌面多栏 / 手机单栏+底部导航）
- 首页仪表盘：今日任务、打卡日历、单元进度、成就
- 错误处理：JSON 导入校验（格式错误明确报错定位）；词库为空引导导入；localStorage 损坏安全重置；代理失败自动降级语音；AI 失败不阻断功能
